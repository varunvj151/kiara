# Kiara Technology Stack

## Language
Python is the primary language because of its strong machine learning ecosystem, rapid experimentation cycle, and broad community support.

## Deep Learning
PyTorch is the initial choice because it offers flexibility, research friendliness, and excellent support for modern transformer experimentation.

## Tokenization
Hugging Face Tokenizers are a strong starting point for benchmarking and rapid iteration, especially for tokenizer experiments.

## Experiment Tracking
TensorBoard and Weights & Biases are suitable options for training analysis and experiment monitoring as the project grows.

## Configuration
YAML is preferred for configuration because it is simple, human-readable, and well-suited to experimentation.

## Version Control
Git is used to preserve reproducibility, support collaboration, and track changes across experiments.

## Why this stack
The stack is chosen to support fast iteration, transparent experimentation, and long-term extensibility without overcommitting to a single framework too early.
