# Kiara Benchmark Plan

Kiara will be evaluated through measurable benchmarks rather than vague claims. These benchmarks form the project's report card.

## Core Benchmarks

- HumanEval
- MBPP
- MMLU
- MMLU Pro
- GSM8K
- GPQA
- ARC
- TruthfulQA
- SWE Bench
- LiveCodeBench
- Math500
- AIME

## Evaluation Philosophy

Each model version should be measured against the same benchmarks under consistent conditions so that progress is clear and reproducible.
